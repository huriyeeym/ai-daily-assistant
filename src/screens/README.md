# Screens

Screen components for the application.

## Screens

- `HomeScreen/` - Daily entry input screen
- `HistoryScreen/` - Past entries list
- `StatisticsScreen/` - Weekly/monthly statistics
- `SettingsScreen/` - App settings

Each screen follows the structure:
- `index.tsx` - Main screen component
- `styles.ts` - Screen-specific styles
- `components/` - Screen-specific components (optional)
