# Redux Store

Redux Toolkit store configuration and slices.

## Structure

### `/slices`
Redux slices for different features:
- `entriesSlice.ts` - Diary entries state
- `analysisSlice.ts` - AI analysis state
- `themeSlice.ts` - Theme and UI state
- `userSlice.ts` - User preferences

### Files
- `index.ts` - Store configuration and exports
- `hooks.ts` - Typed hooks (useAppDispatch, useAppSelector)
