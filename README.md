# AI Günlük Asistanım 🤖

> Duygularınızı anlayan, size rehberlik eden yapay zeka destekli günlük asistan uygulaması

## 📱 Proje Hakkında

Bu proje, kullanıcıların günlük duygularını ve düşüncelerini paylaşabileceği, yapay zeka destekli bir mobil uygulamadır. Uygulama, kullanıcının yazdığı metinleri analiz ederek duygu durumunu tespit eder ve kişiselleştirilmiş öneriler sunar.

## ✨ Özellikler

- 🎯 **Duygu Analizi**: Pozitif, negatif ve nötr duygu tespiti
- 🧠 **AI Destekli Analiz**: Hugging Face modelleri ile gelişmiş metin analizi
- 📊 **İstatistikler**: Haftalık ve aylık duygu durum trendleri
- 💾 **Offline Destek**: İnternet bağlantısı olmadan geçmiş kayıtlara erişim
- 🎨 **Dinamik Tema**: Duygu durumuna göre değişen renkler
- 📝 **Geçmiş Kayıtları**: Tüm günlük girdilerinizi görüntüleme

## 🛠️ Teknolojiler

- **React Native CLI** - Mobil uygulama framework'ü
- **Redux Toolkit** - State yönetimi
- **React Native Paper** - UI komponenti kütüphanesi
- **AsyncStorage** - Lokal veri saklama
- **Hugging Face API** - AI/ML model entegrasyonu
